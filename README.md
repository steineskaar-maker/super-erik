# Super Erik

Et lite plattformspill i nettleseren. Erik er tre år, har gul regnjakke og blå gummistøvler, og skal hjem til bamsen sin. Hopp over sneglene, samle kjeks og dunk i ?-boksene.

## Spill

Åpne `index.html` i en nettleser, eller spill på GitHub Pages.

- **PC:** piltaster eller A/D for å gå, mellomrom for å hoppe
- **Mobil/nettbrett:** knappene under spillet

Hele spillet ligger i én fil og trenger ingen installasjon.
